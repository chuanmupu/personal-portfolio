PROJECT 001 / 校园信息工具

散落的校园信息，
一个清晰的入口。

合工大校园情报助手，把各学院与部门的公开消息整理到一起，让通知、原文和重要截止时间更容易查找。

项目合工大校园情报助手
核心实现Python / SQLite / 网页
使用方式本地浏览 / 每日邮件
项目笔记
01 / 为什么做02 / 怎样实现03 / 持续运行04 / 真实边界

01 / THE PROBLEM

重要消息，不该靠碰巧看见。

同一所学校的消息，会出现在学院、教务处、学生工作等不同网站。想知道近期有什么报名、哪些材料快截止，需要反复打开多个入口。

这个项目从一个很具体的问题出发：能不能把这些公开信息放到一起，同时保留原文，让查消息这件事少花一点时间？

02 / THE APPROACH

把入口收拢，把依据留下。

01

聚合公开消息

读取学院和部门公开栏目，整理通知标题、发布时间与原文链接。首次收录近期文章，随后持续采集新增消息。

02

按需要查找

按学院、消息类型和关键词筛选，保留历史资料查找入口，从列表返回官方原文核对。

03

看见重要截止

整理有原文依据的报名、申请与材料提交节点。不同办理阶段分别保留，日期不明确的内容继续标注待核实。

03 / KEEP IT RUNNING

从能运行，到持续运行。

项目支持本地查看和多个收件邮箱共享同一份日报。采集任务部署到云服务器后，每天北京时间 08:00 开始运行，完成后推送邮件。

为了避免重复提醒，投递过程会保存状态；任务遇到失败会按计划重试，结果不明的邮件不会直接自动重发。

一次实际验收 / 2026.10.21
583已配置消息来源
544当次正常来源
128本机通过测试

另有 39 个来源部分成功或异常，项目保留了对应原因。这些数字来自该次验收，不代表所有来源持续可用。

04 / WHAT MATTERS

把不确定的地方，也说清楚。

部分通知仅限校内访问，有的旧链接已经失效，有的页面没有完整发布日期。工具会保留能确认的信息和失败原因，而不是把没有读到内容解释成“没有新消息”。

信息聚合提供的是一个更方便的入口。具体资格、时间和要求，仍以官方原文为准。

这是个人项目展示，非学校官方平台。此页面介绍项目，不提供当前实时校园通知。
